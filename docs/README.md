## 🎯 What is this Plugin?

The Strapi Video Chat Plugin enables video and audio calling capabilities within your Strapi V5 application using VDO.Ninja's open-source WebRTC technology.

### Key Features

- ✅ **One-on-One & Group Calls** - Support for individual and multi-party video calls
- ✅ **Audio-Only Mode** - Option for voice calls without video
- ✅ **Screen Sharing** - Share your screen during calls
- ✅ **Real-Time Presence** - See who's online and available
- ✅ **Call History** - Track and review past calls
- ✅ **P2P Technology** - 95% of calls are peer-to-peer (minimal server costs)
- ✅ **Admin UI** - Built-in admin panel for call management
- ✅ **REST API** - Complete API for frontend integration
- ✅ **Secure** - Role-based permissions and encrypted calls
- ✅ **Customizable** - Custom CSS, branding, and configuration

### Technology Stack

- **Backend**: Strapi V5, TypeScript
- **Frontend**: React, Strapi Design System
- **WebRTC**: VDO.Ninja (open-source)
- **Database**: PostgreSQL/MySQL/SQLite (Strapi supported)
- **Real-time**: REST API + Presence system

## 📋 System Requirements

- Node.js >= 18.0.0
- npm >= 9.0.0
- Strapi >= 5.0.0
- Modern browser with WebRTC support (Chrome, Firefox, Safari, Edge)
- HTTPS enabled (required for WebRTC)
